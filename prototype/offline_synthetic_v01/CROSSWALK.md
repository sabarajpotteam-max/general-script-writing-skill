# Three-Stream Research Integration Crosswalk
**Universal Professional Scriptwriting Skill — v0.1**
**Last updated:** 2026-10-27

## Purpose
Map findings from all three research streams into a unified classification:
UNIVERSAL, CONDITIONAL, EXPERIMENTAL, or REJECTED.

---

## Classification Rules

| Class | Criteria | Can enter engine? |
|-------|----------|-------------------|
| **UNIVERSAL** | 3+ independent sources from different domains; professional/ethical standard | Yes (as governance) |
| **CONDITIONAL** | Source-faithful with context requirements; bounded empirical | Yes (with conditions) |
| **EXPERIMENTAL** | Untested hypothesis; caption-only pattern; no causal evidence | Yes (as optional, labelled) |
| **REJECTED** | Blocked, quarantined, or contradicted by stronger evidence | No |
