# Evidence Standards — Universal Professional Scriptwriting Skill

## Epistemic Status Levels

| Level | Meaning | Script Treatment |
|-------|---------|-----------------|
| confirmed | Multiple independent replications, consensus | May state as fact with citation |
| replicated | At least one independent replication | State with citation, note replication status |
| preliminary | Single study or pre-registration only | Qualify: "preliminary evidence suggests..." |
| disputed | Counter-evidence exists | Present both sides; do not resolve in favour of either |
| qualified | Default when status is unstated | Treat as preliminary |
| hypothetical | No empirical support yet | Frame explicitly as hypothesis |

## Rules

1. Every factual claim in the script must reference at least one evidence item [E-XXX].
2. The epistemic qualifier in the claim must not exceed the evidence's epistemic status.
3. A "preliminary" finding cannot be stated as "proven" or "confirmed."
4. When evidence is "disputed," the script must present the dispute, not pick a side.
5. Correlation language ("is associated with," "correlates with") must not be upgraded to causal language ("causes," "leads to") without experimental evidence.
6. Effect sizes must be qualified when available: small (d < 0.2), moderate (0.2–0.8), large (d > 0.8).
7. Sample sizes and population characteristics must be noted for primary research.
8. Replication status must be stated for each key finding.

## Blocked and Quarantined Items

These items must not appear as positive supporting evidence:

- **F-190**: Readability formulas are NOT validated for listening comprehension. This is a negative finding. Using it as evidence that readability formulas work for scripts is incorrect.
- **R052**: Has a non-support relation and cannot serve as a supporting source.
- **K029**: Mechanism-level psychology claims lack YouTube script-effect transfer evidence.
- **K030**: MOOC engagement associations are bounded empirical findings that do not transfer to script effectiveness.
- **K031**: Listening modality comprehension findings are bounded by F-190 non-support.
- **B70–B72**: Original sources have access restrictions. Note the caveat when referencing.

## Source Types

| Type | Weight | Notes |
|------|--------|-------|
| meta_analysis | Highest | Pool of multiple studies |
| experimental | High | Randomized controlled design |
| replication_study | High | Independent confirmation |
| primary_research | Moderate | Single original study |
| observational_longitudinal | Moderate | Correlational but long-term |
| critique | Informational | Challenges another finding |
| pilot_trial | Low | Small sample, preliminary |
| expert_opinion | Low | Not empirical |
| caption_pattern | Descriptive only | No causal inference allowed |
